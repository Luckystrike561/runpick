## features // small script, sharp edges filed off

[01]

› Fuzzy filter

Every script in shell.scripts, in one fzf list. dbm finds db:migrate.

type↑↓EnterEsc
[02]

› Preview first

The pane under the list shows the exact command. Array scripts show one step per line.

--preview
[03]

› Any subdirectory

Reads the project root devbox exports, so devbox run pick works from src/deep/down.

$DEVBOX_PROJECT_ROOT
[04]

› Brings its own tools

The plugin pins jq and fzf as devbox packages. Nothing to install on the host.

jq@1.8.1fzf@0.74.3
[05]

› JSONC aware

// and /* */ comments are stripped before parsing, without eating the https:// in your strings.

///* */
[06]

› Stays out of the way

The picker never lists itself. A script of yours named pick always wins.

--list--print
[07]

› npm scripts too

With --npm, list the scripts of your package.json and run the pick as npm run <name>, from the directory you invoked devbox.

--npmnpm run build
[08]

› Same sharp edges

--list, --print, --preview and --args work unchanged on npm scripts. Preview shows the real command, not the script name.

--preview--args
[09]

› Node stays yours

The plugin never ships Node. Whatever your own devbox.json provides is what runs, whatever the lockfile.

npmpnpm

## install // three steps, one of them is typing

  1. 01

    Include the plugin

    Add it to your project's devbox.json. Pin a tag: an included plugin runs in your shell.

    "include": ["github:Luckystrike561/runpick/tags/1.2.0"]
  2. 02

    Pick

    From anywhere in the project. devbox fetches jq and fzf on first run.

    devbox run pick
  3. 03

    Run

    Enter hands the chosen script to devbox run. Esc exits without running anything.

A complete devbox.json

{
  "$schema": "https://raw.githubusercontent.com/jetify-com/devbox/main/.schema/devbox.schema.json",
  "include": ["github:Luckystrike561/runpick/tags/1.2.0"],
  "shell": {
    "scripts": {
      "build": "echo 'compiling...' && sleep 1 && echo 'built dist/app'",
      "test": ["echo 'running 42 tests'", "sleep 1", "echo 'all green'"],
      "lint": "echo 'no issues found'",
      "db:migrate": "echo 'applied 3 migrations'",
      "db:seed": "echo 'seeded 100 rows'",
      "release": ["echo 'tagging v1.2.0'", "echo 'pushed'"]
    }
  }
}

The npm scripts it can pick

Add --npm to pick from a package.json instead. runpick lists its scripts and runs the pick as npm run <name>, so the preview under the list shows the command npm will run:

{
  "name": "acme-web",
  "scripts": {
    "build": "vite build",
    "test": "vitest run",
    "lint": "eslint .",
    "dev:web": "vite",
    "release": "changeset publish"
  }
}

then: devbox run pick:npm — or, from anywhere in the project, bash "$RUNPICK_BIN" --npm.

## options // inside devbox shell, $RUNPICK_BIN points at the script

commanddoes
devbox run pickpick a script, then run it
devbox run pick --argspick, then type arguments for the script
bash "$RUNPICK_BIN" --printpick, then print devbox run <name> instead of running it
bash "$RUNPICK_BIN" --listlist script names, one per line
bash "$RUNPICK_BIN" --npmpick from the package.json scripts and run them with npm run
bash "$RUNPICK_BIN" --versionprint the version

Already have a script named pick? Yours wins. Give the picker another name:

"runpick": ["bash \"$RUNPICK_BIN\" \"$@\""]

## faq // and known limits

Why don't scripts from my other plugins show up?

runpick reads the project's own devbox.json. Scripts added by other plugins are not listed.

Does it handle comments and trailing commas?

// and /* */ comments, yes. Trailing commas, not yet.

Can I track main instead of a tag?

You can, but an included plugin runs in your shell, so tracking main means running whatever lands there. Pin a tag and bump it on purpose.

Do I need fzf or jq installed?

No. The plugin declares both as devbox packages, so devbox provides them inside the project environment.

Does it pick npm scripts?

Yes, with --npm. It reads the package.json in the directory you ran devbox run from and runs the pick as npm run <name>. Your own devbox config has to provide npm: the plugin does not ship Node.
